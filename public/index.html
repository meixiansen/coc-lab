01 / 判定

严格，但不是绝对

在 27″ 屏、60 cm 处观看时，3.05 µm 的模糊已接近人眼分辨极限。

02 / 虚化

背景超过门槛

8 m 处的弥散为 18.6 µm，是允许 CoC 的 6.1 倍，已经明显失焦。

像素正在成为瓶颈

02 / SENSITIVITY

一个变量，四种结果

每张卡片只改变一个参数。注意区分：哪些数字改变的是真实光学模糊，哪些只是观看条件重新定义了“可接受”。

03 / MODEL

公式，以及公式没有说的事

实验台采用一阶薄透镜与几何光学近似。它不模拟手机的计算摄影，却能清楚展示 CoC 在景深与虚化之间扮演的两个角色。

01

允许弥散圆

c = 2D tan(θ/2) · ds / dd

人眼观看条件下，先把显示器上的可辨模糊换算回传感器：D 为观看距离，θ 为视角分辨力，ds / dd 为传感器与显示器的尺寸比。

经典规则：c = dsensor / 1500 ｜ 像素规则：c = k · p
02

超焦距与景深

H = f² / (Nc) + f
snear = s(H−f) / (H+s−2f)
sfar = s(H−f) / (H−s)

当对焦距离 s ≥ H 时，远界变为无穷远。允许 CoC 越小，超焦距越远，景深越窄。

03

真实弥散圆

c(D) = f² |D−s| / [N · D · (s−f)]

D 为物距，s 为对焦距离。它由镜头和拍摄设置决定，与屏幕大小、观看距离无关；这正是“实际模糊”和“允许 CoC”的分界线。

对焦 ∞ 时：c(D) ≈ f² / (N·D)
04

衍射斑

ØAiry = 2.44 λ N (1+m)

小底手机像素极小，f/1.8 的艾里斑就可能覆盖约 2 个像素。收光圈会增加景深，但也会把衍射斑推过采样极限。

λ = 550 nm ｜ m = f / (s−f) ｜ 1 px ≈ 1.18 µm
!

CoC 不是一个物理常数

它是“多大模糊仍然可接受”的约定。把照片放大到 100%、靠近屏幕观看，或者换一个更严格的判据，景深表会立刻改变，但照片里的真实光学模糊没有变。手机的计算摄影、多帧合成、镜头像差和算法虚化都在这套模型之外。
